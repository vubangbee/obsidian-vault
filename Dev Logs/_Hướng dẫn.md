# Dev Logs – nhật ký kỹ thuật

> [!info]- For future agent
> Log từng phiên làm kỹ thuật (debug, automation, setup). Tên `YYYY-MM-DD - Mô tả.md`, `tags: [devlog]`, link tới `Projects/` và `Jobs/` liên quan.

- Ghi vấn đề → cách sửa → kết quả. Log lỗi đã gặp để lần sau tra cứu.
