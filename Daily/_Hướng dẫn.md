# Daily – ghi chú hằng ngày

> [!info]- For future agent
> 1 note/ngày, tên `YYYY-MM-DD.md`. Ghi việc đã làm, số liệu nhanh, quan sát. Mọi agent đọc daily gần nhất trước khi làm việc để nối ngữ cảnh.

- Frontmatter tối thiểu: `date`, `tags: [daily]`. Thêm `mood`/`energy` 1–5 nếu muốn.
- Dùng `Templates/Daily.md` khi tạo mới.
