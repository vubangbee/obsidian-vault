# 09 Playbooks – quy trình chuẩn

> [!info]- For future agent
> Chứa quy trình chuẩn dùng lại được: test creative, scale/tắt quảng cáo, phân bổ ngân sách, đối soát lead, nhịp review. Mỗi playbook là 1 note `type: playbook`, có bước làm + checklist + ví dụ ẩn danh.

- Agent không tự sửa playbook khi chưa hỏi chủ vault.
- Bài học mới rút ra → đối chiếu playbook, có gì đáng giữ thì cập nhật playbook.
