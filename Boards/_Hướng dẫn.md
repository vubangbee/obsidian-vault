# Boards – bảng Kanban

> [!info]- For future agent
> Bảng kéo-thả (Personal, Work...). Mỗi board là 1 note có `kanban-plugin: board`. Cần cài community plugin Kanban mới mở được.

- Cột là `##` heading, thẻ là dòng `- [ ]`. Xong việc tick, đừng xóa thẻ.
