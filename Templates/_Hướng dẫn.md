# Templates – mẫu ghi chú

> [!info]- For future agent
> Mẫu dùng lại khi tạo note mới. Hiện có: Daily, Project, Task, Person, Bài content cá nhân. Tạo note mới thì copy template tương ứng, điền frontmatter, đổi tên đúng quy ước.

- Quy ước tên: Daily `YYYY-MM-DD.md`, Dev log `YYYY-MM-DD - Mô tả.md`, Person tên đầy đủ, Project tên riêng.
